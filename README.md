**Melvin** is intended to be an open source, community managed Discord app, completely void of paywalls, and always up-to-date. Melvin is entirely configurable via app commands tied to each module, but also via the web-dashboard, which is intended to mirror the app commands. This is Melvin's official repository.

Clone the repo, fill out the example env, join the [support server](https://discord.gg/cPcPPVvFW9) if any issues come up.
